## 1. Get your API key

Sign up at the Direkt dashboard and copy your API key from **Settings → API Keys**.

## 2. Create a quote

```bash expandable lines
curl -X POST http://159.223.110.114:3000/api/quote \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
		"fromChainId": 8453,
		"toChainId": 56,
		"fromToken": "0x0000000000000000000000000000000000000000",
		"toToken": "0x0000000000000000000000000000000000000000",
		"amount": "1",
		"recipient": "0xa110c77fa4b07ab601e63edEAd99ddb8f1df22c"
}'
```

## 3. Show the address to your user

Display `depositAddress` in your UI. The user sends exactly `amount` of `currency` on the specified `chain` to that address.

## 4. Poll for status

```bash
curl http://159.223.110.114:3000/api/status/pay_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Poll every 5–10 seconds until `status` is `confirmed` or `completed`.

| Status | Meaning |
| --- | --- |
| `AWAITING_DEPOSIT` | Waiting for the user to send |
| `EXECUTING` | Transaction seen on-chain, waiting for confirmations |
| `COMPLETED` | Fully settled |
| `EXPIRED` | No payment received before expiry |
| `FAILED` | Payment failed or wrong amount |
