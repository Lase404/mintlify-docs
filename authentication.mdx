---
title: "Authentication"
description: "How to authenticate with the Direkt API."
---

Direkt uses two authentication styles depending on the endpoint.

## Quote endpoint — `x-api-key` header

```bash
curl --location 'http://159.223.110.114:3000/api/quote' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

## All other endpoints — Bearer token

```bash
curl --location 'http://159.223.110.114:3000/api/status/...' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

## Getting your API key

1. Sign in to the Direkt dashboard
2. Go to **Settings → API Keys**
3. Copy your key — it starts with `dp_`

<Warning>
  Never expose your API key in client-side code or public repositories. Always call Direkt from your backend.
</Warning>

## Error responses

| HTTP Code | Reason |
|---|---|
| `401` | Missing or invalid API key |
| `403` | Key revoked or lacks permission |
