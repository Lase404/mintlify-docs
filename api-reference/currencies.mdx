---
title: "GET /api/currencies"
description: "List all supported tokens and the chains they are available on."
---

## Request

```
GET http://159.223.110.114:3000/api/currencies
Authorization: Bearer YOUR_API_KEY
```

## Response

```json
[
  {
    "symbol": "USDT",
    "name": "Tether USD",
    "chains": ["ETH", "BSC", "POLYGON", "TRON"]
  },
  {
    "symbol": "USDC",
    "name": "USD Coin",
    "chains": ["ETH", "BSC", "POLYGON", "ARBITRUM", "BASE"]
  },
  {
    "symbol": "NATIVE",
    "name": "Native Token",
    "chains": ["ETH", "BSC", "POLYGON", "ARBITRUM", "BASE", "TRON"]
  }
]
```
