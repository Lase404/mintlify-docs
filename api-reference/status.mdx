---
title: "GET /api/status/:id"
description: "Fetch the current status of a payment."
---

## Request

```
GET http://159.223.110.114:3000/api/status/:id
Authorization: Bearer YOUR_API_KEY
```

### Path parameters

| Parameter | Description |
|---|---|
| `id` | Payment ID returned from `POST /api/quote` |

### Example

```bash
curl http://159.223.110.114:3000/api/status/pay_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Response

```json
{
  "id": "pay_abc123",
  "status": "confirmed",
  "amount": "50",
  "currency": "USDT",
  "chain": "BSC",
  "txHash": "0xdeadbeef...",
  "confirmations": 15,
  "reference": "order_123",
  "confirmedAt": "2025-01-01T12:08:43Z"
}
```

## Status values

| Status | Description |
|---|---|
| `pending` | No transaction detected yet |
| `detected` | Transaction on-chain, awaiting confirmations |
| `confirmed` | Required confirmations reached — safe to fulfil |
| `completed` | Fully settled |
| `expired` | Quote expired before payment arrived |
| `failed` | Payment failed or wrong amount sent |
